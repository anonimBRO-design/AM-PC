### Akar 1 — layer media mati menutupi kanvas
Layer `9DDE...jpeg` (`amproj:` — tak pernah terunduh) t[0–19.5] **seluruh durasi** di atas
semua foto → placeholder full-frame. **Fix:** `renderBaseLayerContent` skip layer tanpa

### Akar 2 — rantai efek membunuh konten (BUG UTAMA)
Probe `readPixels` per-efek (`[dbg-chain]`) + per-pass (`[dbg-pass]`) membuktikan:
foto (55,49,49) → `tile` ✓ → `exposure` ✓ → **`gaussianblur` → (0,0,0,0)** → semua layer
berefek = (0,0,0,255) hitam opak.

Dua sub-akar:
1. **`inputImg` di-chain per pass** — padahal model AM: `inputImg` = input **asli** efek di
   **semua** pass (fallback `gaussianblur` saat `strength<=0` membaca `inputImg`), sedangkan
   buffer antar-pass dibaca eksplisit via param (`downImg`/`hblur`/`vblur`). Chain per-pass
   → fallback membaca buffer kosong → (0,0,0,0). **Fix:** `curIn` tidak di-update per pass.
2. **Param `srcType:"comp"`** (`lift`/copybg) butuh komposit kanvas **di bawah** layer —
   kode mengikat buffer kosong. **Fix:** salin komposit kanvas ke `_compScene`
   (`copyTexImage2D` dari FBO null) sebelum loop efek; binding tekstur param mengikuti
   `srcType` (content→input asli, comp→compScene, buffer→buf_<id>).
3. Bonus: pass efek harus `gl.disable(BLEND)` (overwrite full-frame); composite final
   `gl.enable(BLEND)` sebelum `setBlendMode`.

Catatan penting: `strength=0` pada gaussianblur proyek = **nilai asli** (blur dimatikan
user di AM) — **bukan** keyframe hilang. Perilaku AM yang benar = pass-through (fallback),
bukan hitam.
