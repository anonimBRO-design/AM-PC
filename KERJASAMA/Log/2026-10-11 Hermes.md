## Intel untuk Antigravity — sisa 107 shader gagal (semua level pipeline/sanitizer)

| # | Jml | Gejala | Resep |
|---|---|---|---|
| A | 48 | `'==' : wrong operand types — uniform float vs const int` (mis. `originType==0`). AM shader era GLSL ES 1.00; ES 3.00 menghapus konversi implisit int→float | sanitizer regex di `cleanSource`: `([=!<>]=?)\s*(-?\d+)(?![\d.])` → `$1 $2.0` |
| B | 29 | `Illegal use of reserved word`: `sample` (26 efek), `varying` (7), `filter` (1) — identifier pakai kata kunci ES 3.00 | rename word-boundary di deklarasi uniform **dan** source (mis. `sample→sampleC`). Catatan: `cube2` pakai `varying mat4 invOrient;` (gaya ES1) — perlu keputusan strip/convert, bukan sekadar rename |
| C | 15 | syntax error `smooth` — param bool bernama `smooth` (kata kunci ES 3.00) | rename (`smooth→smoothP`) di decl + source |
| D | 8 | `saturate` — HLSL-ism, tidak ada di GLSL | tambah helper prelude: `float/vec2/vec3/vec4 saturate(x) = clamp(x, 0.0, 1.0)` |
| E | 4 | `inverse` — fungsi user bentrok builtin ES 3.00 (`cube, flip, flip2, flip3`) | rename definisi + pemanggilan (`inverse→inverseM`) |
| F | 3 | `'*' : vec4 * vec3` — param `orient` dipakai sebagai mat4 (`tra * orient`) tapi dideklarasikan vec3 (`360-reorient-sphere, spherize, vrcombined`) | butuh tipe param `orient→mat4` di pipeline + binding renderer |

- Perkiraan: fix A–D menyelesaikan mayoritas sisa; sebagian efek mungkin punya error lapis kedua (muncul setelah error pertama hilang) — jalankan `npm run verify:shaders` tiap selesai satu fix untuk ukur progres.
- Catatan penting: `blendGrain`/`applyDisplace`/`blendColor` **BUKAN** fungsi hilang — `blendGrain` & `applyDisplace` didefinisikan di `grunge.xml` sendiri; `blendColor` di `glow.xml` adalah variabel lokal. Akar error tetap saturate/reserved-word.
